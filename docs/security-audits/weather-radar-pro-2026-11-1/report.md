# Static Security Audit — "Weather & Radar" Android APK (re-signed build)

- **Audit date:** 2026-10-10
- **Scope:** defensive, static analysis only. The APK was never executed, installed, patched, or redistributed; this summary contains no bypass instructions.

**Verdict: BLOCK — do not install.** Provenance is the install-blocking basis: the artifact packages WetterOnline's app under a third-party crack re-signing key, so nothing inside can be attested to the vendor.

## Signing identity

- Owner and issuer: `CN="rockz5555 OU=Droid Freedom Unit O=Droid Freedom Inc L=Unknown S=Unknown C=LK"`
- Self-signed 2048-bit RSA, `SHA256withRSA`, valid 2014-12-04 → 2044-11-26
- SHA-256 fingerprint: `0C:FB:46:63:83:1A:0F:B8:D6:97:3A:AD:44:E2:21:A8:BA:78:F7:F6:84:BD:0B:17:D3:B4:4B:EC:82:31:64:84`
- `X-Android-APK-Signed: 2, 3` — the v2/v3 signing block was regenerated by the modder, so the signature chain attests to the crack identity, not the vendor

| --- | --- | --- | --- |

| info | D5, N1–N5 | Cleared: no dynamic code loading, no trojan/RAT, no SMS/contacts/overlay abuse, no C2 host, no native tampering | all layers |

The modded-malware differential was **negative**: no injected trojan/RAT, no dynamic dex loading, no SMS/contacts/overlay abuse, no C2 host, no native tampering — the known bad actor is the re-signing itself.

## Toolchain

Node v26.11.1, OpenJDK 27, REA CLI 6.3.0, JADX engine `jadx-headless-mcp-0.7.1-all.jar` (SHA-256 `6e5eacf500b64292bfb73c49797c1958f6ee44646e43e868039ae7feb573ff75`).

Full evidence (decoded manifest, 16,505-class inventory, URL dumps, signing cross-checks, native-library report) is preserved in git history at commit `ce4ca74` under `docs/security-audits/weather-radar-pro-2026-11-1/evidence/`.

## Recommendation

Do not install this build. If the app is wanted, install the vendor build from Google Play on the same versionCode; report the re-signing to the vendor.
